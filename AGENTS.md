# Working rules

- At the start of every session, read `AGENTS.md` and `HANDOFF.md`, then do **only** the next step listed in `HANDOFF.md`. Don't scan the whole codebase; open only the files that task touches.
- One stage per session. At the end, update `HANDOFF.md`, commit, push, stop.
- Run only related tests while working; run the full suite once at the end.
- Keep command output short: quiet flags, last lines only, never print whole files or full logs.
- Summaries to the user are under 15 lines.
- Ask before any task needing more than about 30 steps.
